# 📚 DII Library App

A cross-platform library management and book browsing application built for **Dushanbe Innovation Institute**.

## 🚀 Features
- **Real-Time Catalog:** Browse books by department (Computer Science, AI, Biotech, Business, Math).
- **User Authentication:** Firebase Auth setup for student sign-in and profile management.
- **Search & Filter:** Dynamic search across titles, authors, and categories.
- **Responsive Web & Mobile Layout:** Optimized UI for desktop browsers and mobile screens.

## 🛠️ Tech Stack
- **Frontend:** Flutter / Dart
- **Backend:** Firebase (Firestore, Authentication)
- **State Management & UI:** FlutterFlow / Provider / Google Fonts
